# קול תורה (Kol Torah)

אפליקציית Android בעברית לתמלול שיעורי תורה, עריכת הטקסט וייצוא לקובץ Word תואם DOCX.

## מה יש בפרויקט
- ממשק RTL בעברית.
- הקלטת שמע מקומית ל-WAV PCM 16-bit, 16kHz.
- ייבוא קובצי WAV מסוג PCM 16-bit mono/stereo.
- מנוע תמלול Whisper רב-לשוני שרץ מקומית, עם שפת יעד עברית.
- הנחיית מונחים תורניים בסיסית ומילון אישי של החלפות מילים אחרי תמלול.
- טיוטה מקומית, בחירת גופן וגודל טקסט.
- ייצוא למסמך DOCX שניתן לפתוח ב-Microsoft Word או בעורך תואם.
- אין הרשאת רשת בזמן הריצה: ההקלטות והתמלול מעובדים במכשיר.

## מגבלות ידועות בגרסה הראשונית
- המודל הרב-לשוני אינו מאומן במיוחד על הברה אשכנזית. הנחיית מונחים ומילון החלפות עשויים לעזור בכתיב של מונחים, אבל אינם משנים את המודל ואינם מבטיחים זיהוי מדויק של כל הגייה.
- ייבוא שמע נתמך כרגע עבור WAV PCM 16-bit בלבד. הקלטות מתוך האפליקציה נשמרות בפורמט הזה.
- מסמך DOCX מכיל את טקסט התמלול בעיצוב עברי בסיסי; אין עדיין עורך עשיר מלא לכותרות/הדגשות ולא נוצרים סיכומים או שכתוב אוטומטי.
- גופן מותאם מכתב יד אינו ממומש בגרסה זו.
- היעד המינימלי הוא Android 6.0 (API 23), לא Android 4.
- המודל גדול, ולכן קובץ ה-APK יהיה גדול משמעותית מאפליקציה רגילה. הבנייה האוטומטית מצרפת את המודל לאפליקציה כדי לאפשר תמלול גם ללא הורדה אחרי ההתקנה.

## בניית APK
ה-workflow ב-.github/workflows/android.yml:
1. מתקין Java 17, Gradle, Android SDK ו-NDK.
2. מוריד את מודל Whisper הרב-לשוני ggml-tiny.bin בזמן הבנייה.
3. בונה את הספרייה המקורית whisper.cpp ואת APK במצב debug.
4. מעלה את הקובץ app-debug.apk כ-artifact של GitHub Actions.

אפשר להפעיל את הבנייה ב-GitHub דרך Actions → Build Kol Torah APK → Run workflow. לאחר הצלחה, פותחים את ריצת הבנייה ובוחרים Artifact בשם kol-torah-debug-apk.

## שימוש
1. מתקינים את ה-APK.
2. מקליטים שיעור או בוחרים קובץ WAV PCM 16-bit.
3. לוחצים על "תמלל שיעור". העתקת המודל לאחסון האפליקציה מתבצעת בפעם הראשונה בלבד.
4. עורכים את הטקסט ומגדירים כללי החלפה בהגדרות מילון ההחלפות.
5. לוחצים על "ייצוא למסמך Word (.docx)" ובוחרים מיקום שמירה.

הערה: מומלץ תמיד לעבור ידנית על תמלול שיעור, במיוחד שמות, מקורות ומונחים תלמודיים. התמלול לא נועד להחליף הגהה אנושית.
